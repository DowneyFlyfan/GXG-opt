# Qwen3-0.6B scratch baseline sweep: 500M-token subset on ABA A100

## Objective

Train scratch-initialized Qwen3-0.6B baseline optimizers on a fixed FineWeb-Edu subset. The requested data split is 500,000,000 training tokens and 100,000,000 validation tokens. Each final baseline run uses five epochs, so it exposes 100,007,936 label tokens per epoch and 500,039,680 label tokens in total.

## Placement decision

AWS Elastic Compute Cloud (EC2) A100 launches were attempted with the required `owner=yufanwang` instance tag and a 128 GiB root solid-state drive. Eight-A100 `p4de.24xlarge` and `p4d.24xlarge` placements failed for insufficient capacity; an Oregon `p4d.24xlarge` retry also failed, and Ohio had a 8 virtual central processing unit quota that could not place the 96 virtual central processing unit instance. No AWS instance was created. The run therefore uses ABA GPU 0: NVIDIA A100 80 GB Peripheral Component Interconnect Express. ABA GPU 1 is reserved by an unrelated vLLM service and was not modified.

## Dataset

Source cache: `.cache/Fineweb_Edu_2B`.

Derived cache: `.cache/Fineweb_Edu_500M_train_100M_val`.

- Training stream: deterministic 500,000,000-token prefix of the immutable packed source training stream; SHA-256 `cca9a6621c55bd78263a2be6c5826fbe72990bb1d2ec16f46c60cdafe02869c0`.
- Validation stream: the source 100,000,000-token validation stream; SHA-256 `2971d4b2c7418e841516f8ddca6cc42f0d858294772b488533f1ede7875dc917`.
- Sequence length: 2,048 tokens.

The cache loader verified both file sizes and SHA-256 digests before training.

## Training plan

- Initialization: scratch.
- Baselines: AdamW, Muon, and Muown.
- Global batch size: 64 sequences.
- Per-device microbatch: 8 sequences.
- Gradient accumulation: 8 steps.
- Formal epochs: 5.
- Formal updates per epoch: 763.
- Formal updates per baseline: 3,815.
- Parameter screening: 123 updates (16,121,856 label tokens) for 3 AdamW, 2 Muon, and 3 Muown rate configurations; the lowest validation perplexity configuration for each optimizer advances to its five-epoch run.
- Weight decay: 0.1, appropriate because the model has more than 200 million parameters.
- Metrics: validation perplexity at steps, with final metric-versus-step and metric-versus-time Portable Network Graphics figures rendered after the formal runs.

## Live execution

Run label: `scratch_500m_5ep_batch64_aba_a100_v1`.

The baseline driver started on ABA GPU 0 with `nohup` and writes its live log to `.cache/qwen3_0p6b/logs/scratch_500m_5ep_batch64_aba_a100_v1.log`. Initial verification observed GPU 0 at 100% utilization with 43.9 GiB allocated; GPU 1 remained assigned to vLLM.

## Near-saturation batch-size probe and restart

The initial microbatch-8 sweep used only 47,053.91 MiB of the 80 GiB A100, so its first two completed AdamW screens are retained as preliminary evidence but are not used to select the final baseline hyperparameters. A separate one-update scratch AdamW probe established that microbatch 16 with gradient accumulation 4 preserves the required effective batch size of 64 and completes without out-of-memory failure. Its peak allocation was 78,675.50 MiB and its one-update elapsed time was 21.09 seconds. The probe files and the interrupted third microbatch-8 screen were deleted after recording the result.

The definitive sweep was restarted under run label `scratch_500m_5ep_batch64_aba_a100_mb16_v1` with microbatch 16 and accumulation 4. It repeats all tuning candidates before choosing the AdamW, Muon, and Muown five-epoch baselines.

The first full microbatch-16 screening trial subsequently failed during the standard 12-batch validation pass: after one initial metric, the loss projection required an additional 298 MiB beyond the 79.25 GiB device capacity. That trial was terminated and all of its partial files were removed. Microbatch 8 with accumulation 8 is therefore the largest configuration that completes both training and required validation while preserving exact global batch size 64.

The sweep driver now recognizes already completed screens and resumes them safely. The microbatch-8 run label `scratch_500m_5ep_batch64_aba_a100_v1` resumed with its two complete AdamW screens, then proceeds with AdamW candidate 3, all Muon and Muown screens, and the three five-epoch formal baselines.

AdamW screening candidate 3 (`learning_rate=0.006`) completed at validation perplexity 1,302.4572 after 16,121,856 label tokens in 1,196.21 seconds, with 47,053.91 MiB peak memory. AdamW candidate 1 (`learning_rate=0.001`, perplexity 726.2857) is therefore selected for the five-epoch formal baseline.
