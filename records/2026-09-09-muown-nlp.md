# Muown baseline on GPT2-12x512

## Method

This baseline implements **Muown: Row-Norm Control for Muon Optimization** on
the fixed NLP GPT2-12x512 workload.  For each Muon-eligible matrix the
effective parameter is represented as \(W = \operatorname{Diag}(g / r) R\),
where \(r\) contains the row norms of \(R\).  The direction variable \(R\)
receives the tangent-projected Momentum Muon update and the row gains \(g\)
receive Adam updates.  This retains the ordinary model parameter as the
effective weight used by the forward pass.

The companion angular-step-size paper is used as the geometric rationale for
the row-normalized parameterization; it does not add a second optimizer to this
single-baseline study.

## Paper-faithful settings

- Direction update: Nesterov Momentum Muon with five Newton--Schulz steps and
  the standard \(0.2\sqrt{\max(m,n)}\) scale already used by the repository.
- Gain update: Adam with \((\beta_1,\beta_2)=(0.9,0.95)\) and the same learning
  rate as the direction update.
- Weight decay: **0.0 by default**.  The Muown paper reports its primary
  configuration without decoupled weight decay; inheriting the task's 0.01
  decay would test a different configuration.
- Data/model/schedule: retained WikiText-103 stream, GPT2-12x512, effective
  batch 48 (micro-batch 8, accumulation 6), five epochs for the selected run.

## Tuning protocol

The first screen is at learning rate 0.005, the deliberately aggressive
candidate.  A stable winner is promoted directly to one fresh, five-epoch
matched run; a lower-rate bracket is not run without evidence that the
aggressive candidate is unstable.  No Muown run is launched while the active
Multi-Step Spectral Geometry run owns the local GPU.

## Implementation verification

Commit `b13e3ee` adds an explicit `weight_decay` override to `run_trial` and
makes `run_muown.py` default it to zero.  The focused Muown and GPT baseline
selection tests passed (5 tests), and the command-line help exposes the
override.  Numerical results will be appended after each completed screen.

## Screen 1: aggressive learning rate 0.005

The matched one-epoch, zero-decay screen completed in 1,962.17 seconds with a
peak allocation of 8,616 MB. It reached **0.71491432**, exceeding the tuned
Muon epoch-one reference (0.71167119) by 0.00324313. The aggressive rate is
therefore stable and is currently the selected Muown candidate; promote it to
the required fresh five-epoch run rather than spending the local GPU on a
lower-rate bracket that has no evidence of need.

## Final five-epoch result

The fresh `lr0005_b8_a6_final` run completed successfully with effective batch
48, zero weight decay, 54,682,624 parameters, 8,616 MB peak memory, and
9,792.30 seconds (2h 43m 12s). Its validation next-token accuracy trace was:

| Epoch | Muown | Tuned Muon | Difference |
| ---: | ---: | ---: | ---: |
| 1 | 0.71491432 | 0.71167119 | +0.00324313 |
| 2 | 0.73472786 | 0.73050563 | +0.00422223 |
| 3 | 0.74497795 | 0.74212519 | +0.00285276 |
| 4 | 0.75307274 | 0.75136948 | +0.00170326 |
| 5 | **0.75617790** | 0.75503159 | **+0.00114632** |

Muown beats both retained final references: it is 0.03243065 above AdamW
(0.72374725) and 0.00114632 above Muon (0.75503159). The comparison is
matched on data, model, five epochs, and effective batch size; its
micro-batch/accumulation pair is 8/6 rather than the references' 12/4.
The completed result and its dedicated step/time figures are
`results/nlp/nlp_gpt_12x512__lr0005_b8_a6_final__muown.json` and
`results/nlp/muown_lr0005_b8_a6_final_metric_{steps,time}.png`.
