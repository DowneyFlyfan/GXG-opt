# Computer Vision Baseline Curve Rendering Record

## Input metrics

- Domain: Computer Vision.
- Models: ResNet-20, VGG-11, DenseNet-121, MobileNetV2, and ViT-Tiny.
- Optimizers: AdamW and Muon.
- Metric streams: ten JSON Lines files in `metrics/cv`.
- Resolution: one validation loss and validation accuracy observation per
  epoch, 100 epochs per optimizer/model pair, 1,000 observations total.

## Rendering settings

- Renderer: dependency-free Scalable Vector Graphics generated by
  `src/cv/plotting.py`.
- Dashboard: five rows, with validation loss at left and validation accuracy
  at right for each model.
- Individual charts: one two-panel chart per model.
- Raster previews: generated from the SVG files with `rsvg-convert`.
- No baseline training or metric rewriting occurred.

## Outputs

- `results/cv/curves/cv_metric_dashboard.svg`.
- `results/cv/curves/cv_metric_dashboard.png`.
- `results/cv/curves/{resnet20,vgg11,densenet121,mobilenet_v2,vit_tiny}_metrics.svg`.
- Corresponding PNG previews for the five individual charts.

## Verification

- The renderer unit test verifies a dashboard plus one chart for every
  requested model.
- The dashboard was rendered and visually checked after PNG conversion.
